# Existing Star Wars artwork

Images are stored locally so character sheets do not depend on hotlinks. Source URLs, creator credits, and checksums are recorded in sources.json. No images in this directory were AI-generated.

Most images are official Star Wars Databank stills and artwork (Lucasfilm). Additional equipment assets come from the Star Wars community, the 501st reference library, and credited artists. Some generic concepts, careers and species use representative Star Wars depictions. These third-party images are not relicensed by the system code license.
