# Tokenizer 2 tokens

69 framed tokens composed using the installed Tokenizer 2 version 2.1.0 and its plain-marble-frame-grey.png frame. Portrait sources are documented in assets/starwars-original/sources.json. Original portraits remain unchanged; only the separate token compositions are cropped or fitted and framed. The Tokenizer 2 module code is not bundled. Baked token images work without the module; edit the saved layers with Tokenizer 2 installed.

Homebrew NPC and vehicle portraits are representative images, not claims that those original sample names are canon characters.
