## Original starter compendia (optional)

We provide [23 optional starter compendia with 239 fan/homebrew entries](starter-kit/README.md): equipment, weapons, armour, species, careers, specializations, talents, narrative powers, adversaries, vehicles and an original short adventure. **No official commercial books are included.** Install as a module via: https://raw.githubusercontent.com/Mitos7/StarWarsFFG/foundry-v14-mitos/starter-kit/module.json
To import your legally-owned official data, use StarWarsFFG's built-in **OggDude Dataset Importer** from the Compendiums sidebar with a ZIP of your local OggDude Data folder. Always back up your world first.

## Mitos7 - Public installation (Foundry V14)

Install the main **Star Wars FFG + Genesys** system using this manifest in Foundry **Game Systems -> Install System -> Manifest URL**:

`https://github.com/Mitos7/StarWarsFFG/releases/latest/download/system.json`

The current stable version is **2.0.5-mitos.10**. It retains the original Star Wars title logo, previous Foundry V14 fixes, and Genesys game mechanics.

For third-party add-ons, Foundry can offer the optional **Star Wars FFG - Mitos Add-on Collection** during system installation. It can also be installed manually using the **Add-on Modules -> Install Module -> Manifest URL** field:

`https://raw.githubusercontent.com/Mitos7/StarWarsFFG/foundry-v14-mitos/addons/collection/module.json`

See the [addon catalog](addons/CATALOG.md) for the 20 available modules and dependencies, their publisher links, patch provenance and compatibility warnings. Installation does not enable modules in any game world. Some older addons are verified only up to Foundry V10-V13 and may be incompatible with V14. Different UI replacements can conflict with each other.

Six community add-on mirrors preserve their original software licenses. Other packages download directly from their authors; no non-redistributable third-party code is copied into this repository.

This is an independent community fork, not endorsed by Lucasfilm, Disney, FFG, Edge Studio, Foundry VTT or the original system maintainers. This installation branch is for V14; ApplicationV2/V16 work remains on a separate experimental branch.

# StarWarsFFG

This is an unoffical implementation of the [Fantasy Flight Games Star Wars](https://www.fantasyflightgames.com/en/starwarsrpg/) series of Star Wars RPGs systems for Foundry VTT.

Full support for other Genesys-based systems is also included.

This system is made by fans, for fans, and is not associated with Fantasy Flight Games or their partners in any way.

The system for Foundry VTT contains no rules or proprietary content from the various official RPG sourcebooks by Fantasy Flight Games. It is intended to make the process of enjoying the Star Wars and Genesys RPG systems via an online tabletop experience as easy as possible but you will still need to purchase any and all official sourcebooks you desire in order to enjoy this system as intended.

For more info and documentation including various "How-To" guides, please check out the Wiki section of our GitHub repo.

# Installing Star Wars FFG game system

1. Open Foundry VTT
2. Go to the "Game Systems" Tab
3. Click the "Install System" button
4. Copy the Following link into the "Manifest URL" section:
   https://raw.githubusercontent.com/StarWarsFoundryVTT/StarWarsFFG/master/system.json
5. Click Install, after a few seconds the system should be installed.
